01Overview

What it is

A snake arena that fits on a 1.4 inch screen.

BezelSnake is a front end for slither.io — it speaks the v11 protocol. It runs as a Wear OS app, and the same build runs in a browser tab.

You control a snake, eat to grow, and try not to run into anyone else. That part is unchanged. What is different is everything around it: the frame budget, the effects, the type sizes, and the loop that stops the moment the game leaves the screen.

02Play

How to play

Install the APK on your watch, or open the browser build in any tab. There is no account and no sign-up.

You steer with the rotating bezel, so your finger never sits on top of the board. One hand, one thumb, no menus.

Rounds are short by design. A run fits between two notifications — which is the whole point of putting a game on a watch.

03Trade-offs

What you get, what you give up

A watch is a constrained machine. Everything below is a consequence of that, not an accident.

Pros

  • Built for Wear OS rather than squeezed onto it
  • Bezel control keeps the screen clear
  • Free and open source
  • Runs in a browser with nothing to install
  • Rounds sized for a few spare minutes

Cons

  • No iOS or phone app — Wear OS and browser only
  • Fewer modes than a desktop .io game
  • Deliberately plain visuals
  • Less depth than a full-size arena
